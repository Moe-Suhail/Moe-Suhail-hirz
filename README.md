# حرز

تطبيق React عربي للأذكار والقرآن والسبحة، بتصميم RTL نظيف ومناسب للاستخدام اليومي.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية.

## الموجود الآن

- تبويبات للأذكار والقرآن والسبحة والمفضلة.
- جلب جميع أقسام الأذكار من API موثق لحصن المسلم.
- جلب المصحف كاملًا بالنص العثماني من API موثق.
- بحث عربي بسيط داخل الأذكار والسور والآيات المحملة.
- عداد تكرار للأذكار مع حفظ التقدم في `localStorage`.
- سبحة إلكترونية مع حفظ العدد.
- مفضلة للأذكار والسور.
